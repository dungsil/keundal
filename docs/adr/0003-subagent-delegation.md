# 서브에이전트는 부모 실행 안에서 한 번만 위임한다

부모 실행은 `delegate_task` 도구로 독립된 작업을 자식 에이전트에 맡기고 결과를 기다린다. 자식은 같은 모델과 도구를 쓰지만 부모 대화를 받지 않으며 다시 위임할 수 없다. 부모 실행마다 동시에 준비하거나 실행하는 자식 수를 `maxActiveSubagents`로 제한하며 기본값은 8이다. 한도에 도달한 호출은 자식을 만들지 않고 `rejected` 상태와 `ACTIVE_LIMIT_REACHED` 오류를 반환한다.

자식의 종료 상태는 `completed`, `failed`, `rejected`로 구분한다. 자식이 실패해도 형제와 부모 실행은 계속되고, 부모 취소는 모든 자식에게 전파한다. 결과는 마지막으로 받은 비어 있지 않은 어시스턴트 답변이며, 실패한 자식의 부분 응답은 실패 상태와 함께 보존한다. 선택적인 `label`은 80자까지 허용하고 진행 표시에 사용한다.

## 검토한 선택

- 자식에게 후속 메시지를 보내고 백그라운드에서 계속 실행하는 안: 부모 요청이 끝난 뒤의 자식 수명과 영속적인 소유권 계약이 필요하므로 사용하지 않는다.
- 재귀 위임과 자식별 모델 선택: 동시 실행 한도와 비용 계산이 호출 트리 전체로 번지므로 사용하지 않는다.
- 외부 CLI 공급자와 대화 복제: 현재 도구 실행 계약과 저장소 계약에 없는 수명을 요구하므로 사용하지 않는다.
