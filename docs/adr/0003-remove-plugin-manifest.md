# JSON 매니페스트 대신 UI 설정으로 기능을 구성한다

web 로컬 모드와 desktop은 `keundal.plugins.json`을 읽지 않고, 사용자가 UI 설정에서 선택 기능을 켜고 끈다. desktop만 UI에서 외부 모듈을 추가할 수 있다. 원격 서버는 환경 변수로 기능을 끄고, 외부 구현은 TS 조립 API로 넣는다.

## 검토한 선택

- 매니페스트를 유지하고 그 위에 사용자 설정을 덧씌우는 안: 기능을 구성하는 방법이 두 가지로 나뉘므로 사용하지 않는다.
- UI가 매니페스트 파일을 직접 고치는 안: UI가 모듈 경로까지 바꾸게 되어 신뢰 경계가 넓어지므로 사용하지 않는다.
