# 라벨

스킬은 정규 역할 이름으로 라벨을 가리킨다. 이 파일은 그 이름을 이슈 트래커에서 쓰는 라벨 문자열에 대응한다.

## 트리아지 상태 역할

이 다섯 역할은 들어온 요청이 거치는 상태를 나타낸다. `vibe-plan`의 트리아지 단계에서 이 역할을 쓴다.

| 정규 역할          | 우리 트래커의 라벨    | 의미                                     |
| ------------------ | -------------------- | ---------------------------------------- |
| `needs-triage`     | `상태:분류필요`      | 유지보수자가 이 이슈를 평가해야 함        |
| `needs-info`       | `상태:정보필요`      | 보고자의 추가 정보를 기다리는 중          |
| `ready-for-agent`  | `상태:에이전트작업`  | 명세가 완전해 사람이 지켜보지 않아도 작업하는 에이전트(AFK)가 작업할 준비가 됨 |
| `ready-for-human`  | `상태:사람작업`      | 사람이 직접 구현해야 함                   |
| `wontfix`          | `상태:수정안함`      | 조치하지 않음                            |

스킬이 역할을 언급하면(예: "AFK 준비 트리아지 라벨을 적용하라") 이 표에서 그 역할의 라벨 문자열을 찾아 쓴다.

실제로 쓰는 어휘에 맞추려면 오른쪽 칸을 편집한다.

## 계획 라벨

`vibe-plan`과 `vibe-deep-plan`이 계획 산물을 표시할 때 이 라벨을 쓴다. 계획 유형은 호스트형 명세나 계획 이슈와 결정 맵을 표시한다. 맵 상태는 노력(맵 하나가 다루는 큰 작업)의 색인이 아직 진행 중임을 표시한다. 결정 유형은 자식 티켓이 어떻게 해결되는지 기록한다.

| 정규 역할  | 우리 트래커의 라벨    | 의미                                            |
| --------- | -------------------- | ----------------------------------------------- |
| plan      | `유형:계획`          | 이 이슈는 명세 또는 계획이거나 결정 맵인 부모 계획 산물 |
| map       | `상태:초안`          | 이 이슈는 결정 맵이다. 노력의 색인이며, 할 일이 아니다 |
| research  | `유형:조사`          | 주요 출처를 읽는 백그라운드 서브에이전트로 해결  |
| prototype | `유형:프로토타입`    | 반응을 살필 일회용 산출물로 해결                 |
| grilling  | `유형:인터뷰`        | 한 번에 한 질문씩 나누는 대화로 해결             |
| task      | `유형:작업`          | 결정 전에 반드시 먼저 해야 하는 수동 작업         |

## 두 축

`상태:`는 "이것이 어떤 상태인가"에 답하고, `유형:`은 "어떤 계획 산물이거나 어떤 방식으로 결정을 해결하는가"에 답한다. 이슈는 **축당 최대 한 개의 라벨**만 가진다.

호스트형 명세나 계획 이슈에는 `유형:계획`과 알맞은 트리아지 상태를 함께 붙인다. 결정 맵에는 `유형:계획`과 `상태:초안`을 함께 붙인다.

`상태:초안`은 트리아지 상태와 같은 축이므로 맵에서 트리아지 상태를 배제한다. 맵의 결정 티켓에는 네 결정 `유형:` 라벨 가운데 하나만 붙이고, 트리아지 상태는 붙이지 않는다.

맵에 남은 결정이 없어지고 `vibe-plan`이 구현 티켓을 발행한 뒤에만 구현 티켓에 트리아지 상태를 다시 적용한다. 스킬은 정규 역할 이름을 기준으로 말한다. 위 표의 오른쪽 칸에 있는 라벨 문자열만 사용한다. 그 문자열을 영어로 옮기지 않는다. 영어로 옮긴 예는 `status:draft`, `type:plan`, `type:research`다.
