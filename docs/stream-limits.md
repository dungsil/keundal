# 생성 스트림의 자원 한도

공급자가 출력 토큰 설정을 무시하거나 토큰으로 계산하지 않는 메타데이터를 보내더라도 로컬 자원을 무한히 사용하지 않도록 생성 스트림에 별도의 한도를 적용합니다. 이 한도는 공급자의 출력 토큰 한도와 독립적이며, 먼저 도달한 한도가 실행을 종료합니다.

| 대상                              | 한도                  |
| --------------------------------- | --------------------- |
| 공급자 SDK가 읽는 HTTP 응답 본문  | 32 MiB                |
| 공급자 응답의 원시 이벤트 전체    | 32 MiB, 16,384개      |
| generation 실행의 이벤트 전체     | 32 MiB, 16,384개      |
| HTTP SSE 실행의 이벤트 전체       | 32 MiB, 16,384개      |
| 개별 이벤트                       | 8 MiB                 |
| 개별 이벤트의 중첩 깊이와 값 개수 | 깊이 64, 값 262,144개 |

바이트 검사는 JSON 문자열의 이스케이프와 UTF-8 크기를 상한으로 계산합니다. 객체의 키와 구분자도 포함하며 숫자와 제어 문자는 보수적으로 계산하므로 실제 전송 크기보다 조금 일찍 한도에 도달할 수 있습니다. 크기를 재기 위해 먼저 전체 값을 직렬화하거나 복사하지 않습니다. 순환 객체와 사용자 정의 `toJSON` 함수는 허용하지 않습니다.

OpenAI, Anthropic, Gemini는 SDK가 본문을 해석하기 전에 응답 바이트 수를 검사합니다. 원시 이벤트는 변환 전에 검사하므로 텍스트 조각뿐 아니라 도구 인자, 인용, 암호화된 추론, 서명, 최종 스냅숏도 한도에 포함됩니다. OpenAI의 완료·실패 이벤트도 검사합니다. SDK의 토큰 계산 응답에도 HTTP 본문 한도가 적용됩니다.

세 저장소의 generation 실행은 도구의 후속 모델 요청을 포함하여 전체 이벤트를 합산합니다. 초과 이벤트는 조립하거나 journal에 기록하지 않습니다. 실행은 실패로 종료하고, 이미 수락한 부분 결과는 보존합니다. 기존 기록을 읽거나 복구할 때는 새 실행 한도를 소급 적용하지 않습니다.

HTTP 계층은 SSE 이벤트를 검증하거나 직렬화하기 전에 한도를 검사합니다. 소켓의 쓰기 버퍼가 차면 `drain`을 기다린 뒤 다음 이벤트를 요청합니다. 연결을 종료하면 대기를 해제하고 실행을 취소합니다.

이 한도는 현재 고정값입니다. 매우 긴 정상 응답이나 메타데이터가 많은 응답도 한도에 도달하면 실패할 수 있으며, 모델의 최대 출력 토큰 설정이 모든 출력의 수신을 보장하지는 않습니다.
