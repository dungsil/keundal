# @keundal/ui-settings-llm

설정 페이지에 LLM 공급자 섹션과 프롬프트 프리셋 섹션을 제공하는 Nuxt 레이어입니다. 두 섹션은 별도의 Cordis 플러그인으로 내보내며, 각각 `ctx.slots`와 `ctx.chatRuntime`에 의존합니다.

## 등록하는 슬롯

| 내보내기          | 슬롯               | 키              | 순서 | 설명                                                                                           |
| ----------------- | ------------------ | --------------- | ---- | ---------------------------------------------------------------------------------------------- |
| `./plugin`        | `settings.section` | `llm`           | 10   | `/settings/llm`의 공급자 목록, API 키·주소·요청 헤더 편집. `?provider=`로 공급자를 지정합니다. |
| `./prompt-plugin` | `settings.section` | `system-prompt` | 25   | `/settings/system-prompt`에서 프롬프트 프리셋을 편집하고 선택합니다.                           |

공급자 섹션은 `ctx.chatRuntime`에서 저장된 설정(`settings`), 선택한 모델(`model`), 기능(`capabilities`)을 받습니다. 저장할 때 `store.stop()`으로 진행 중인 응답을 멈춘 뒤 `saveSettings()`를 호출합니다. 각 내보내기는 해당 슬롯 하나만 등록합니다.

**설정 → 큰달 플러그인**에서는 `@keundal/ui-settings-llm`과 `@keundal/ui-settings-llm/prompt-plugin`을 독립적으로 선택합니다. 프롬프트 UI는 `requires`로 `@keundal/prompt`에 의존합니다. 이 항목은 새 구현 플러그인 패키지가 아니라 공통 에이전트 루프의 프롬프트 프리셋 기능을 제어합니다. 기능을 끄면 프롬프트 UI를 일시 해제하되 저장한 활성화 선택과 프리셋은 유지합니다. 다시 켜면 활성화해 둔 UI만 복원하며, 직접 끈 UI는 꺼진 상태를 유지합니다. LLM 공급자 설정 UI에는 영향을 주지 않습니다.

프롬프트 프리셋은 `promptPresets`와 `savePromptPresets()`를 받습니다. 생성·복제·삭제·이름 변경과 적용할 프리셋 선택을 지원합니다. 편집할 프리셋과 적용할 프리셋은 별도로 고릅니다. 편집 중 다른 프리셋을 선택해도 작성한 내용은 유지되며, 저장 버튼을 눌러야 적용됩니다. 적용할 프리셋을 `없음`으로 저장하면 기본 지침만 사용합니다.

텍스트 블록은 이름, 역할(`system`·`user`·`assistant`), 내용과 사용 여부를 편집하고 복제·삭제·이동할 수 있습니다. 대화 기록 블록은 앞뒤 지침 사이로 이동할 수 있지만 삭제하거나 복제할 수 없습니다. 도구 호출과 결과를 자르거나 중복하지 않도록 전체 기록을 한 번만 넣습니다. 앱과 에이전트의 기본 시스템 지침은 프리셋 밖에서 앞에 유지합니다.

변수는 영문자나 밑줄로 시작하는 키와 문자열 값으로 정의합니다. `{{key}}`는 값을 한 번만 치환하며, 값 안의 템플릿이나 코드는 실행하지 않습니다. 텍스트 블록에는 변수 하나를 비교하는 조건을 붙일 수 있습니다. `eq`·`ne`는 문자열을 정확히 비교하고, `gt`·`gte`·`lt`·`lte`는 비어 있지 않은 유한 숫자만 비교합니다. 조건이 거짓이거나 블록이 꺼져 있으면 해당 내용을 보내지 않습니다. 미리보기에는 실제 대화 대신 대화 기록 위치를 표시합니다.

저장한 설정은 이 기기의 `localStorage`에 보관하며 계정과 동기화하지 않습니다. 다음 응답부터 적용하고, 이미 실행 중인 응답·제목 생성·서브에이전트에는 적용하지 않습니다. 기존 사용자 지침은 기본 프리셋으로 읽습니다. 외부 프리셋 포맷이나 스크립트 언어는 지원하지 않습니다.

```ts
import * as llm from '@keundal/ui-settings-llm/plugin'
import * as prompt from '@keundal/ui-settings-llm/prompt-plugin'

ctx.plugin(llm)
ctx.plugin(prompt)
```
