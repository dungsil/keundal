# @keundal/ui-media

미디어 자료库 화면과 설정 구역을 제공합니다. 재생, 자막 표시, 전사와 번역 실행, 다운로드 시작을 한 화면에서 다룹니다.

## 등록하는 슬롯

| 슬롯               | key       | 역할                                        |
| ------------------ | --------- | ------------------------------------------- |
| `settings.section` | `media`   | 설정 화면의 미디어 구역, 순서 130           |
| `layout.sidebar`   | `library` | 자료库 화면으로 가는 사이드바 항목, 순서 20 |
| `page.library`     | 없음      | `/library` 화면의 본문                      |

`page.library`는 `@keundal/ui-layout`이 선언하고, 이 패키지가 등록합니다.

## 데이터 접근

화면은 `ctx.chatRuntime`의 `platform.media`를 사용합니다. 이 값은 호스트가 미디어 기능을 조립했을 때만 있습니다.

- 웹 앱은 원격 에이전트 호스트에 연결할 때 `@keundal/chat/media`의 `createHttpMediaClient`로 만듭니다.
- 데스크톱 앱은 사이드카가 준 주소와 토큰으로 같은 클라이언트를 씁니다.
- 실행 방식이 미디어를 제공하지 않으면 구역과 사이드바 항목이 나타나지 않습니다.

컴포넌트는 플랫폼 객체를 직접 받지 않습니다. 플러그인의 `inject`가 묶은 함수만 props로 전달합니다.

## 화면 구성

자료库 화면은 폴더 경로 입력, 영상 목록, 재생기, 자막 선택, 실행 폼으로 이루어집니다.

1. 폴더 경로를 입력하고 자료库를 만들거나 다시 읽습니다.
2. 영상을 고르면 호스트의 `/media/video` 주소로 재생합니다. 현재 자막 줄을 화면 아래에 겹쳐 보여 줍니다.
3. 전사는 발화 언어와 음성 모델을 받아 실행하고, 끝나면 원본 자막 트랙을 저장합니다.
4. 번역은 고른 자막 트랙을 대상 언어와 LLM 모델로 번역하고 새 트랙으로 저장합니다.
5. 다운로드는 링크와 저장 폴더를 받아 작업을 시작하고, 끝날 때까지 2초마다 진행률을 갱신합니다.
6. 클립은 시작과 끝 시각을 받아 목록에 모으고, 내보내기와 FCPXML 쓰기를 실행합니다.

다운로드, 전사, 클립 내보내기 폼은 데스크톱에서만 보입니다. 로컬 실행 파일이 필요한 기능이기 때문입니다.

## 재생 주소

`<video>`는 요청 헤더를 붙일 수 없으므로 재생 주소에 토큰을 쿼리로 넣습니다. 호스트는 `GET /media/video`에서만 쿼리 토큰을 받고, `Range` 요청을 지원합니다.

## 한계

재생 위치에 따른 자막 강조는 현재 줄만 표시합니다. 단어 단위 강조와 자막 스타일 설정은 없습니다.

클립은 자막 줄을 고르지 않고 시작·끝 시각을 직접 입력합니다. 타임라인 뷰와 드래그 구간 선택은 없습니다.

내보내기 진행률은 표시하지 않습니다. 클립 하나가 끝날 때까지 기다린 뒤 결과만 보여 줍니다.

자료库 목록은 항목 제목만 표시합니다. 표지 그림과 정렬 선택은 없습니다.
