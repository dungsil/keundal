# @keundal/workspace-changes

에이전트의 한 턴에서 바뀐 파일을 기록합니다. 턴 시작 시점의 실제 파일과 도구 실행 뒤의 파일을 비교하므로, 턴 전에 만든 미커밋 변경을 이번 턴의 변경으로 계산하지 않습니다. 같은 파일을 여러 번 바꾸면 최초 내용과 마지막 내용을 비교하고, 원상 복구한 파일은 목록에서 제외합니다.

## 호스트에서 사용하기

`createAgentHost()`에 `workspace: '/absolute/project'`를 지정하거나 웹·데스크톱 호스트에 `KEUNDAL_WORKSPACE=/absolute/project`를 설정합니다. 지정한 폴더 안에서 기존 파일 접근 정책을 적용하는 읽기·목록·쓰기·수정 도구와 변경 기록을 함께 활성화합니다. 기존 파일은 먼저 읽어야 수정할 수 있습니다. 셸 도구는 자동으로 등록하지 않습니다.

이미 도구를 직접 구성했다면 `workspaceChanges: { cwd: '/absolute/project' }`만 지정해 기록 기능을 연결할 수 있습니다. Git 작업 폴더 안에서는 도구 종류와 관계없이 변경을 비교하므로, 별도로 등록한 셸 도구의 수정·삭제도 기록됩니다.

```ts
import { recordWorkspaceChanges } from '@keundal/workspace-changes'

const config = {
  model: 'model-id',
  maxOutputTokens: 4096,
  wrapRunStream: recordWorkspaceChanges({ cwd: '/absolute/project' })
}
```

## 기록과 표시

`keundal.workspace-changes` CUSTOM 이벤트는 `runId`, 파일 경로, 생성·수정·삭제 상태, 추가·삭제 줄 수, 변경 전후 텍스트를 담습니다. 이 이벤트는 generation journal에 저장되며 모델 입력에는 포함되지 않습니다. 원격 대화에는 `runId` 참조만 저장하며, 다시 열 때 journal에서 원문을 가져옵니다. Diff 원문이 후속 대화 요청에 누적되지 않습니다. SQLite 호스트를 재시작해도 journal에서 당시의 비교 내용을 복원할 수 있습니다. 채팅 화면은 턴마다 최신 기록 하나를 표시하고 원본·수정본·Diff 보기를 제공합니다.

도구 결과마다 부분 기록을 갱신하고 정상 종료 때 완료 기록을 저장합니다. 후속 생성이 실패하면 부분 기록을 남깁니다. 취소나 프로세스 종료 때는 마지막으로 journal에 저장한 부분 기록까지만 보장합니다. 마지막 기록 이후 발생한 변경은 포함되지 않을 수 있으므로 부분 기록은 완료 기록과 구별해서 표시합니다.

## 범위와 제한

- Git이 설치된 작업 폴더를 대상으로 합니다. Git이 없거나 명령이 실패하면 기록 불가 상태를 표시합니다.
- `git ls-files`로 추적 파일과 무시되지 않은 미추적 파일을 찾습니다. index, refs, 작업 파일을 수정하거나 Git 필터를 실행하지 않습니다.
- 무시된 파일, 작업 폴더 밖의 파일과 서브모듈 내부 변경은 수집하지 않습니다. 심볼릭 링크의 대상 내용은 읽지 않습니다. 턴 중 무시 규칙이 바뀌어도 최초 대상은 계속 비교합니다. 처음에 무시되었다가 대상에 포함된 파일은 원본을 확보하지 못했다는 사유를 표시합니다.
- 턴 실행 중 사용자나 다른 실행이 같은 폴더를 바꾸면 그 변경도 포함될 수 있습니다. 기록은 파일 변경의 주체를 판별하지 않습니다.
- 기본 제한은 파일 500개, 파일당 64 KiB, 스냅샷당 텍스트 512 KiB입니다. 파일 수를 넘으면 기록 불가로 표시하고, 크기 제한·바이너리·읽기 실패는 파일별로 표시합니다.
- 줄 비교는 50ms 또는 편집 거리 2,000을 넘으면 파일 전체 교체로 표시합니다. UI는 변경 구간 주변 3줄을 보여 주며 Diff 표시를 2,000줄로 제한합니다. 원본과 수정본 탭에서는 기록된 전체 텍스트를 확인할 수 있습니다.
- 비어 있는 파일의 생성·삭제와 마지막 개행 변경도 구별합니다. 이름 변경은 삭제와 생성으로 표시합니다.
- 저장된 원본과 수정본은 대화·실행 데이터의 일부입니다. SQLite 데이터 파일은 작업 폴더 밖에 두거나 Git에서 무시하도록 설정합니다.

`maxFiles`, `maxFileBytes`, `maxSnapshotBytes` 옵션으로 기록 한도를 조절할 수 있습니다. `maxFiles`는 500 이하이며 모든 값은 양의 정수여야 합니다.
