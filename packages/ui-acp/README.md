# @keundal/ui-acp

외부 ACP 에이전트가 보고한 계획, 도구 실행 상태, 파일 변경 전·후 내용과 사용량을 채팅 메시지와 분리된 패널에 표시합니다. web과 desktop의 공통 Nuxt 레이어이며 `chat.observer`와 `chat.execution` 슬롯에 등록합니다. ACP 기록이 없는 대화에는 패널을 표시하지 않습니다.

## 기록과 복원

- 어시스턴트 메시지 ID인 `runId`로 Generation Journal을 읽고, 실행 선택 목록에서 과거 작업도 확인합니다.
- `keundal.acp.update`의 원본 ACP 도구 ID와 뒤따르는 AG-UI 도구 ID를 연결합니다. 같은 ACP 도구 ID를 다음 실행에서 재사용해도 기록을 섞지 않습니다.
- 계획과 사용량은 최신 스냅숏으로 바꾸고, 도구 갱신은 생략하거나 null인 필드를 보존합니다. 명시한 `content`와 `locations` 목록은 교체합니다.
- 화면을 지연 로딩하기 전에 이벤트 구독을 시작합니다. 저장소가 일괄 기록 중이면 먼저 받은 실시간 이벤트도 유지하고, 종료 후에는 영속 기록의 상태를 따릅니다.
- 재접속하거나 호스트를 재시작해도 journal로 같은 작업 상태를 복원합니다. 외부 에이전트나 도구를 다시 실행하지 않습니다. 취소·실패·중단된 작업의 미완료 단계를 성공으로 바꾸지 않습니다.
- 실행 기능이 해제되어도 저장된 작업을 읽도록 이 UI는 항상 등록합니다.

## 표시 범위

컨텍스트 토큰은 ACP `usage_update.used / size`이며 입력·출력 토큰 합계가 아닙니다. 비용은 해당 ACP 세션의 누적 금액과 통화입니다. 파일 변경사항은 에이전트가 보고한 Diff이며 실제 Git 변경 목록이나 적용 승인 화면을 대신하지 않습니다. 도구가 Diff 콘텐츠를 교체하거나 비우면 패널에도 반영합니다. 경로와 코드, 도구 출력은 HTML로 실행하지 않고 텍스트로 표시합니다.

외부 에이전트의 인증·모델·모드 선택은 바꾸지 않습니다. 일반 채팅은 ACP에 앱 기본 시스템 지침을 붙이지 않고 텍스트 사용자 메시지를 전달합니다. 사용자 지침·프롬프트 프리셋 등 지원하지 않는 입력은 실행 전에 오류로 알립니다. 일반 채팅과 호스트에서 시작한 ACP 실행, 저장된 기록을 표시할 수 있습니다. 입력과 세션 수명의 제한은 [`plugin-agent-acp` 문서](../plugin-agent-acp/README.md#설정과-제한)를 참고하세요.

## 검증

`pnpm --filter @keundal/ui-acp test`와 `pnpm --filter @keundal/ui-acp typecheck`로 데이터 변환을 검사합니다. 화면은 실제 앱과 ACP 프로세스를 연결해 직접 조작하며 UI 테스트 코드는 추가하지 않습니다.
