# @keundal/plugin-compaction-summary

주입된 `llm`으로 이전 대화를 요약하는 `compaction` 구현입니다. `simpleAgentPlugin`과 함께 등록하면 입력 예산을 초과한 대화를 축약합니다.

```ts
import summaryCompactionPlugin from '@keundal/plugin-compaction-summary'

// llm을 제공하는 플러그인을 먼저 등록합니다.
await ctx.plugin(summaryCompactionPlugin, {
  keepRecentMessages: 6,
  maxSummaryTokens: 1024
})
```

| 설정                 | 기본값 | 설명                                                                                                     |
| -------------------- | ------ | -------------------------------------------------------------------------------------------------------- |
| `keepRecentMessages` | `6`    | 최근에 보존할 최소 메시지 수입니다. 사용자 턴과 도구 호출·결과를 분리하지 않도록 보존 범위를 확장합니다. |
| `maxSummaryTokens`   | `1024` | 요약 호출마다 허용하는 최대 출력 토큰 수입니다. 모델의 출력 한도 이내로 제한됩니다.                      |

설정값은 양의 정수여야 합니다. 요약에는 요청의 `model`을 사용하며, 별도의 공급자나 API 키 설정은 필요하지 않습니다.

시스템·개발자 메시지와 최근 대화는 원문을 보존합니다. 나머지 메시지는 JSON 대화 자료로 전달하며, 생성한 요약은 권한이 높은 시스템 지시가 아닌 사용자 메시지로 삽입합니다. 반환값에는 `messages`, 요약 문자열인 `summary`, 실제 요약에 반영한 메시지 ID인 `sourceMessageIds`가 포함됩니다. 입력과 세션 원본은 변경하지 않습니다.

요약 요청은 실제 `llm.countTokens()` 결과에 따라 여러 묶음으로 나눌 수 있습니다. 각 묶음은 직전 요약을 함께 받아 누적 요약을 만듭니다. 따라서 긴 이력은 여러 LLM 호출과 토큰 계산 요청이 필요합니다. 요약 호출에는 원래 요청의 도구, 상태, 컨텍스트를 전달하지 않으며, 최종 입력의 예산 검사는 원래 요청의 메타데이터까지 포함합니다.

이미 예산 안에 들어오는 입력은 요약 호출 없이 그대로 반환합니다. 보존할 메시지만으로 예산을 초과하거나, 단일 메시지가 요약 요청 한도를 넘거나, 최종 요약을 포함한 입력이 예산을 초과하면 오류를 반환합니다. 최근 대화를 임의로 삭제하거나 무한히 재요약하지 않습니다. 이미지 등 멀티모달 내용은 JSON에 담긴 표현만 요약하며, 이미지를 직접 해석하는 기능은 제공하지 않습니다.

외부 `AbortSignal`과 플러그인 해제는 진행 중인 모델 조회·토큰 계산·요약 스트림에 취소 신호를 전달합니다. 공급자 오류, 빈 요약, 끝나지 않은 텍스트 스트림은 그대로 실패 처리합니다.
